## 1. 两个缺陷的根因（实测定位，非推测）

### 缺陷 A：visual-dark P2 目录出界
- 直接根因：`wengao_ppt/visual.py::classify` 的几何规则 `top < 2.0 and sz >= 22 → title`
  把**生成稿正文占位符**（top=1.9in、22pt）误判为页面标题 → apply_type_scale 把目录
  8 条抬到 30pt（TARGET_PT title）→ 8×0.85in=6.8in 超出正文框（5.1in）→ 出界。
- 促成根因：`add_bullets` 无容量分支（单栏放不下就溢出），且行高估算用
  `22×1.25/72=0.382in/行`，**低于中文行盒实测值 ~0.554in/行**（pt×1.25×1.45/72，
  Songti/STHeiti 行距度量更大）——估算 4.17in vs 实际 5.55in，偏差 ~33%。

### 缺陷 B：P5 来源说明被右侧表格遮挡（六主题同现象）
- 直接根因：`add_chart` 的 rest 表格第 1 列写入 **8 字标签**（`f"{i}.{short}"`，
  short=标签前 8 字），1.0in 窄列必然换行 → 每行膨胀到 ~1.18in（实测），表格实际
  下探 ~6.9in，盖住 6.38in 起的来源注脚右半段（x≈7.2in 起）。PDF 抽字完整 ≠ 可见。
- 佐证：受控实验（同结构表格、第 1 列只放序号）行高 0.5–0.82in、表格仅 ~3.1in。

## 2. 修复（全部确定性，无模型调用）

| 文件 | 修改 | 作用 |
|---|---|---|
| `wengao_ppt/visual.py` | classify：占位符按**类型**定性（TITLE 才是标题；BODY/SUBTITLE 归正文）；非占位符的标题规则阈值 2.0→**1.2in**（生成稿标题在 0.55、正文区自 1.9 起） | 生成稿正文/目录不再被抬到 30pt；visual-dark 正文回到 22pt 基线 |
| `samples/r5_material_to_ppt.py` | 新增 `_bullets_est_h`（实测行盒系数 1.45）；`add_bullets` 增加**双栏分支**（估高超框且 ≥4 条 → 4+4 双栏、栏宽 5.85in、顶锚定），双栏仍超容的条目交溢出续页 | 目录 8 条 4+4 双栏，任何主题有余量；不裁切/不删句/不缩字号/不复制填页 |
| 同上 | `add_chart` rest 表格第 1 列**只放序号**；行高按换行实测口径估算（~19 字/行、0.5–1.1in/行），表格下沿预算止于 6.20in（注脚带 6.38 上方留 0.18 间隙）；放不下的条目交溢出续页 | 表格不再长高盖住注脚；说明全句可见 |
| 同上 | `add_table` 同样加行高预算 + 溢出续页（同类防护） | 全宽表格页同口径防御 |
| 同上 | 双栏文本框**顶锚定**（不用垂直居中）：自适应主题 refine 会重定位框体（实测把第一栏 T 1.9→4.04），MIDDLE 锚定会随框体把文字推出画布 | adaptive 主题 P2 不再出界 |
| `scripts/geometry_gate.py`（新增） | 几何级门禁：逐页量渲染 PDF 文本位置——①全文本在画布内；②全页文本两两不重叠（遮挡门禁，旋转轴标签碎片豁免）；③目录 8 条可见；④内容条款（规范化空白后）；⑤页数 10–20 | 把"可见性"变成可执行门禁，替代"抽字完整/退出码 OK" |
