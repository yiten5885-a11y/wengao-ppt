稳稿 PPT（WenGao PPT）—— 本地优先的 PPTX 生成与美化引擎。

两条路径:① 美化已有 PPTX（结构、字号、配色、对齐一次修齐,不改内容);② 从原始材料(md/txt/docx)自动生成结构规范、事实不丢字的原生 PPTX,自带配图来源与版权审查。

核心差异:所有结论都由独立验收器重读磁盘上的 PPTX/PDF/渲染像素/字形轮廓给出,生成器自己说"做完了"不算数——不会把半成品静默标成可用。六套主题经 WCAG 对比度实算,CLI 与本机网页工作台双入口,支持局部修改与历史回滚。

适合:需要批量产出述职汇报、经营评审、投标演示、培训课件,又不想每次都手动调版式、对字号的个人或团队。

重要前提(请买前确认):"美化已有 PPTX"支持零配置模式(--skip-scene-photos),只需本机装好 LibreOffice 即可,不强制配模型;如果想要文稿自动配上语义相关的场景照片,或者走"由原始材料生成 PPTX"这条路径,就需要你自备一个可用的模型后端(本机 llama-server/Ollama,或自行配置云端 API Key)。当前交付状态为开发候选版(DEVELOPMENT_CANDIDATE):26 种非中文语种的真实端到端生成、50 套完整验收用例尚未全部跑完,已知限制见随包 README 与 KNOWN_ISSUES。自有代码 MIT 协议。
